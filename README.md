# Himanshu Bhat — Portfolio

Static HTML, CSS and vanilla JavaScript portfolio.

For GitHub Pages, publish the main branch from /(root). The target user-site repository is HimanshuBhat001.github.io.

Open index.html to preview locally. Content is in index.html, styling in css/style.css and behavior in js/script.js.

The contact form opens an email draft; it does not send messages automatically.

The profile photo and resume are the user-supplied originals.
